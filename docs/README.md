# oauth-server — docs

OAuth2 / OIDC authorization server for togo — issue tokens to client apps.

- **Install:** `togo install togo-framework/oauth-server`
- **Marketplace:** https://to-go.dev/plugins/oauth-server
- **Source:** https://github.com/togo-framework/oauth-server

See [usage.md](usage.md) for the grants, endpoints, and the Go API.
